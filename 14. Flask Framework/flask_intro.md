# Flask Framework

Flask is a micro web framework written in Python. It is classified as a microframework because it does not require particular tools or libraries. It has no database abstraction layer, form validation, or any other components where pre-existing third-party libraries provide common functions. However, Flask supports extensions that can add application features as if they were implemented in Flask itself. Extensions exist for object-relational mappers, form validation, upload handling, various open authentication technologies, and several common framework-related tools.

## Two main components of Flask are:

1. `WSGI` : The Web Server Gateway Interface is a specification that describes how a web server communicates with web applications. It is a standard interface between web servers and Python web applications or frameworks.

2. `Jinja2` : It is a modern and designer-friendly templating language for Python, modelled after Django’s templates. It is fast, widely used and secure with the optional sandboxed template execution environment.

## Features of Flask:

- Flask is a micro web framework, which means it is lightweight and easy to use.
- It is built on top of the Werkzeug WSGI toolkit and the Jinja2 template engine.
- Flask provides a simple and flexible way to create web applications.
- It has a large and active community, which means there are many resources available for learning and troubleshooting.
- Flask is easy to extend with third-party libraries and extensions, which can add functionality such as database integration, authentication, and more.
- Flask is designed to be easy to use and understand, making it a great choice for beginners and experienced developers alike.
