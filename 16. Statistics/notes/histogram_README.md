# Histogram

## Definition
A **Histogram** is a graphical representation used to show the distribution of numerical data.
It divides the data into **intervals (bins)** and displays the **frequency of values** in each interval.

Unlike a bar chart, the bars in a histogram **touch each other** because the data is continuous.

## Characteristics of Histogram

- Used for **continuous numerical data**
- Bars **touch each other**
- Shows the **distribution of data**
- Helps identify **skewness and spread**

---

## Applications

Histograms are used in:

- Statistics
- Data analysis
- Machine learning
- Quality control
- Population studies
