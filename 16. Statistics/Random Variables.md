# Random Variable

## Definition

A **Random Variable** is a numerical value that represents the outcome of a random experiment.  
It assigns a real number to each possible outcome in the sample space.

In simple terms, it converts random outcomes into numbers so they can be analyzed mathematically.

Example:  
If we toss a coin, we can define a random variable **X** as:

- X = 1 if Head occurs
- X = 0 if Tail occurs

---

# Types of Random Variables

## 1. Discrete Random Variable

### Definition

A **Discrete Random Variable** takes **countable values** (finite or countably infinite).

### Examples

- Number of heads in coin tosses
- Number of students in a class
- Number of defective items in a batch

### Example Problem

Let **X** be the number of heads obtained when tossing a coin two times.

| Outcome | Value of X |
| ------- | ---------- |
| HH      | 2          |
| HT      | 1          |
| TH      | 1          |
| TT      | 0          |

Possible values of **X = {0,1,2}**

---

## 2. Continuous Random Variable

### Definition

A **Continuous Random Variable** takes **infinite values within a range**.

### Examples

- Height of students
- Weight of a person
- Temperature of a city
- Time required to complete a task

### Example

Let **X** be the height of students in a class.

Possible values might be:

- 150.2 cm
- 165.7 cm
- 172.4 cm

These values can take **any value within a range**, therefore it is continuous.

---

# Important Notes

- Random variables are usually denoted by **capital letters** like **X, Y, Z**
- Their values are written in **small letters** like **x, y, z**
- They are used in **Probability and Statistics** to analyze random processes.
