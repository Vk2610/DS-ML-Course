# Measure of Central Tendency

## Definition

Measures of Central Tendency are statistical methods used to determine the central or typical value of a dataset. They summarize a dataset with a single representative value.

The three main measures are:

- Mean
- Median
- Mode

---

# 1. Mean (Average)

Mean is the sum of all values divided by the total number of values.

## Population Mean

Formula:

μ = ( ΣX ) / N

Where:

- μ = Population mean
- ΣX = Sum of all population values
- N = Total number of values in the population

Example:

Population data: 5, 10, 15, 20, 25

Sum = 5 + 10 + 15 + 20 + 25 = 75  
N = 5

μ = 75 / 5 = **15**

Population mean = **15**

---

## Sample Mean

Formula:

x̄ = ( ΣX ) / n

Where:

- x̄ = Sample mean
- ΣX = Sum of sample values
- n = Number of values in the sample

Example:

Sample data: 6, 8, 10, 12

Sum = 6 + 8 + 10 + 12 = 36  
n = 4

x̄ = 36 / 4 = **9**

Sample mean = **9**

---

# 2. Median

Median is the middle value of a dataset when arranged in ascending or descending order.

## Population Median Example

Population data: 3, 7, 9, 11, 15

Middle value = **9**

Population median = **9**

If the number of values is even:

Example:

Population data: 2, 4, 6, 8

Median = (4 + 6) / 2 = **5**

---

## Sample Median Example

Sample data: 5, 9, 13

Middle value = **9**

Sample median = **9**

---

# 3. Mode

Mode is the value that appears most frequently in a dataset.

## Population Mode Example

Population data: 2, 4, 4, 5, 7, 9

Most frequent value = **4**

Population mode = **4**

---

## Sample Mode Example

Sample data: 3, 6, 6, 6, 8, 10

Most frequent value = **6**

Sample mode = **6**

---

# Applications

Measures of central tendency are used for:

- Summarizing large datasets
- Understanding the typical value in data
- Comparing different datasets
- Statistical analysis in research
- Data science and machine learning
